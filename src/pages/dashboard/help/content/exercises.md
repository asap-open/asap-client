# Exercise Library

Browse hundreds of built-in movements or create your own custom exercises.

## Core Features

* **Multi-Parameter Search:** Filter movements by **Primary Muscle** (Chest, Back, Quads, etc.), **Equipment** (Barbell, Dumbbell, Cable, Machine, Bodyweight), and **Category**.
* **Personal Records (PRs):** View historical best performances and estimated 1RM calculations for every movement.
* **Custom Exercises:** Add custom movements with specific target muscle groups, equipment requirements, and tracking types (weighted vs time-based).
