# Getting Started with ASAP

ASAP is designed to help you track workouts, maintain balanced muscle development, and prevent overtraining injuries through intelligent workload analytics.

## App Navigation

* **Desktop:** Use the left sidebar to navigate between **Home**, **Exercises**, **Progress**, and **Profile**. Use the floating `+` button in the bottom right to start a session.
* **Mobile:** Use the bottom navigation bar to switch tabs. Tap the centered `+` button anytime to start a fresh workout or select a saved routine template.

## Logging Your First Workout

1. Tap **`+ Add Session`** and choose **Start fresh session** or **Select a template routine**.
2. Tap **`+ Add Exercise`** to search and add your lifts.
3. Enter your weight and reps for each set, then check the completion box. Tap **Save Session** when done.
