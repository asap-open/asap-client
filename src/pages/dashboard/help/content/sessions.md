# Workout Sessions & Live Logger

The **Session Logger** gives you a fast, focused interface to log sets, reps, timers, and intensity during your workout.

## Features

* **Fresh vs Routine Template:** Start an empty workout from scratch or load one of your pre-configured routines.
* **Automatic Draft Saving:** Your live session is saved continuously in session storage, so you never lose progress if you switch tabs or refresh.
* **Set Tracking:** Log weight (kg), target reps, or duration (for timed exercises like planks).
* **Built-in Timers:** Set stopwatches and rest interval timers directly on exercise cards.
* **Hard Sets / RPE:** Mark challenging sets to accurately calculate training stimulus and fatigue distribution.
